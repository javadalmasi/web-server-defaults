مجموعه صفحات پیش‌فرض وب‌سرور

این مجموعه شامل صفحات استاندارد HTTP برای نمایش خطاهای مختلف سمت کاربر است. کلیه صفحات به زبان فارسی و با پشتیبانی از راست‌چین طراحی شده‌اند.

پشتیبانی فارسی

همه متن‌ها به زبان فارسی و با قلم مناسب

راست‌چین

طراحی راست‌چین مناسب برای محتوای فارسی

واکنش‌گرا

سازگار با انواع دستگاه‌ها و رزولوشن‌ها

نصب خودکار روی سرور

برای نصب خودکار این صفحات خطا روی سرورهای مختلف:
wget https://github.com/javadalmasi/web-server-defaults/archive/main.zip
unzip main.zip && cd web-server-defaults-main
chmod +x install.sh
sudo ./install.sh install

پشتیبانی از: cPanel، DirectAdmin، Nginx، Apache، aaPanel
